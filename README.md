# D4AI

Standalone AI assistant — web + Android (`com.d4ai`).

## Web
- URL: https://d4ai-app.vercel.app/
- Route: `/` only (no school login)

## Android (Code Assist)
Open the **`android/`** folder → Sync → Run.  
See `CODEASSIST.md`.

### On-device features
- **Memory:** conversation history + user facts remembered on the device
- **Phone control (APK):** volume, brightness, open apps, flashlight, vibrate, open system settings (Wi‑Fi / data / hotspot panels)

## Build web
```bash
npm install --legacy-peer-deps
npm run dev
```
